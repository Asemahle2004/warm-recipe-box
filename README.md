# Easy Meals App

Create a modern recipe app called EasyMeals with a warm, user-friendly design. Include recipe cards with meal images, ingredients, preparation steps, cooking time, and difficulty level. Organize recipes into breakfast, lunch, dinner, snacks, and vegetarian categories, and add a search bar and favourites feature. Use a warm orange, cream, and green colour scheme.

This project was built with [Lovable](https://lovable.dev).
